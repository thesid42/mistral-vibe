History may contain `[vibevm:paged-out]` stubs where large old tool outputs were moved to the VibeVM page store to save context. Call this tool with a keyword `query` (or the exact `page_id` from a stub, e.g. `P041`) to restore the original content. If the source file changed since paging, the current file content is returned instead with status `stale_refreshed`, noting the old and new content hashes. By default recall returns the matching regions verbatim, not the whole page; pass `full=true` only when the complete content is actually needed.
