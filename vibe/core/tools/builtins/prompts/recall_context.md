History may contain `[vibevm:paged-out]` stubs where large old tool outputs were moved to the VibeVM page store to save context. When you need detail from a stubbed page, call this tool with a keyword `query` (or the exact `page_id` from a stub, e.g. `P041`) — prefer `recall_context` over `read_file`, `grep`, or re-running the original tool for that same content. If the source file changed since paging, the current file content is returned instead with status `stale_refreshed`, noting the old and new content hashes. By default recall returns the matching regions verbatim, not the whole page; pass `full=true` only when the complete content is actually needed. Excerpts are almost always sufficient; full=true is expensive and capped at ~6k tokens, so prefer a sharper query when an excerpt missed what you needed.
